# CV-builder-app
A React app that converts a sidebar form into a live, editorial-style  CV page

## Features

- **Sidebar editor** with collapsible sections for General Information, Education and Experience
- **Portfolio page** with a General Information section, Education section, Work experience section
- **Education management**: Add or remove multiple qualifications and institutions as needed
- **Work experience management**: Add multiple experiences, each with its own list of responsibilities. Add or remove responsibilities as needed
- **Reusable components**, including a `CollapsibleSection` that handles expand/collapse behavior

- ## Tech Stack

- [React](https://react.dev/)
- CSS (Flexbox, Grid, pseudo-elements)
- Google Fonts: Bebas Neue, Playfair Display, Caveat
